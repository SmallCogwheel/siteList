# 🌐 siteList

내가 만든 웹사이트들을 한눈에 모아볼 수 있는 포트폴리오 사이트입니다.

---

## ✨ 특징

- 📱 반응형 디자인
- 🎯 간단하고 직관적인 UI
- 🔗 프로젝트 링크 한눈에 모아보기

---

## 🛠️ 사용 기술

- **HTML** - 구조
- **CSS** - 스타일링
- **JavaScript** - 동적 기능

---

## 📁 프로젝트 구조

```
siteList/
├── index.html      # 메인 HTML 파일
├── script.js       # JavaScript 동작 로직
├── style.css       # CSS 스타일시트
└── README.md       # 프로젝트 설명 문서
```

---

## 📋 포함된 프로젝트

| 제목 | 설명 |
|------|------|
| 포트폴리오 사이트 | 프로젝트를 정리한 웹사이트 |
| 가위 바위 보 | 코드 덩이와 가위 바위 보 하는 웹사이트 |
| 카페인 계산기 | 카페인을 어느정도 얼마나 섭취하는게 안전한지 알려주는 계산기 |
| Pandas 뉴스 요약 | 뉴스를 요약해주는 사이트 |

---

## 🚀 시작하기

1. 저장소를 클론합니다
```bash
git clone https://github.com/SmallCogwheel/siteList.git
```

2. `index.html`을 브라우저에서 엽니다

---

## ✏️ 프로젝트 추가/수정하기

`script.js` 파일의 `projects` 배열에 새로운 프로젝트를 추가하세요:

```javascript
const projects = [
  {
    title: "프로젝트 제목",
    description: "프로젝트 설명",
    url: "https://example.com"
  },
  // ... 더 많은 프로젝트 추가
];
```
